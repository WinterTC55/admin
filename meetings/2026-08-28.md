# 4 Discussions

## 4.1 Proposed new meeting schedule ([WinterTC55/admin#198](https://github.com/WinterTC55/admin/issues/198))

The committee reviewed the survey results for future meeting time and day, but were still missing a few key respondents. The committee intends to make a final decision regarding future meeting time and day at the meeting on 25 September.

## 4.2 Conversion of minimum common API to ecmarkup ([WinterTC55/proposal-minimum-common-api/#120](https://github.com/WinterTC55/proposal-minimum-common-api/pull/120))

The secretary presented a pull request that converted the content of ECMA-429 into ecmarkup, simultaneously aligning the content on GitHub with the version that the committee and the GA approved in December 2025. The HTML output of this work will be provided to the Ecma secretariat who will host it alongside the other HTML Ecma standards like ECMA-262 and ECMA-402.

If committee members find they prefer to work in bikeshed, they are enthusiastically encouraged to put together pre- and post-processing to convert the output of bikeshed into a format that aligns with Ecma house style, which Ecma would be overjoyed to provide to other future TCs within Ecma.

The overall response to [the pull request](https://github.com/WinterTC55/proposal-minimum-common-api/pull/120) was supportive, and delegates are requested to carefully review it for accuracy and quality before the next meeting of TC55.

## 4.3 Project board ([WinterTC55/admin#197](https://github.com/WinterTC55/admin/issues/197))

The committee set up a [GitHub project board](https://github.com/orgs/WinterTC55/projects/2/views/1) to track work for the remainder of the year, and Owen Buckley (Invited Expert) is owning the maintenance for that board. The committee discussed and decided to add the repositories for the admin, minimum common API, runtime keys, www, Iterable streams, sockets API, and the special “.github” repos. For now, the project is internal-only.

## 4.4 Deploy previews not working ([WinterTC55/admin#178](https://github.com/WinterTC55/admin/issues/178))

This is an issue that triggered before Deno sunset its deploy product, but said sunsetting is entirely relevant. The current deploy process for web properties such as runtime keys and the marketing site does not provide for previews of pull requests out of the box. Owen is seeking input and volunteering to pursue a pilot fix if there is one available. He will connect with James M Snell (Cloudflare) for insight into the Cloudflare product options. Any fix to the minimum common API will presumably be blocked by [\#120](https://github.com/WinterTC55/proposal-minimum-common-api/pull/120).
