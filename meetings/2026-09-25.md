# 4 Discussions

## 4.1 Add nub to Runtime Keys  [WinterTC55/runtime-keys#39](https://github.com/WinterTC55/runtime-keys/pull/39)

The attendees of the meeting reviewed the pull request to add Nub to runtime keys. The committee concluded that this submission does not meet the bar of runtime, and informed the submitter of such. No further action was taken.

## 4.2 [Convert to ecmarkup proposal-minimum-common-api#120](https://github.com/WinterTC55/proposal-minimum-common-api/pull/120)

The attendees discussed the current open pull request to convert the minimum common API text to ecmarkup, and agreed to merge all open suggestions. They did not feel there was quorum to merge the PR into main.

## 4.3 Text based import attributes - [(Minimum common API \#117)](https://github.com/WinterTC55/proposal-minimum-common-api/issues/117)

All present recognized the interop concern, but there was disagreement as to whether defining behaviour around import attributes was within scope for the MCA standard.

**Owen Buckley** (Invited Expert) will attempt to put together proposed text which satisfies scope concerns.
